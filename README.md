# Vertical TabBar Pro

Chrome のタブを縦に並べて管理できる拡張機能です。  
タブの多い作業環境でもスッキリと整理でき、ブックマークとの行き来もサイドパネル一つで完結します。

---

## 導入手順

### 1. ファイルを準備する

ダウンロードした `Vetical-TabBar-Pro-master.zip` を解凍します。  
解凍すると `Vetical-TabBar-Pro-master` というフォルダが作成されます。

### 2. Chrome の拡張機能ページを開く

Chrome のアドレスバーに以下を入力して Enter を押します。

```
chrome://extensions/
```

### 3. デベロッパーモードをオンにする

ページ右上の「**デベロッパーモード**」トグルをオンにします。

### 4. 拡張機能を読み込む

「**パッケージ化されていない拡張機能を読み込む**」ボタンをクリックし、  
先ほど解凍した `Vetical-TabBar-Pro-master` フォルダを選択します。

### 5. サイドパネルを開く

Chrome ツールバーに表示された拡張機能アイコンをクリックし、  
「**サイドパネルを開く**」を押すと縦タブが表示されます。

---

## 機能一覧

### 縦型タブ表示

すべての開いているタブをサイドパネルに縦一列で表示します。  
アクティブなタブは左端のアクセントラインでひと目で識別できます。  
タブ数はツールバーにリアルタイムで表示されます。

---

### タブの操作

| 操作 | 動作 |
|---|---|
| クリック | タブに切り替える |
| 中クリック | タブを閉じる |
| × ボタン | タブを閉じる |
| Ctrl + クリック | ブックマーク登録ポップアップを開く |
| ドラッグ＆ドロップ（上下端） | タブを並び替える |
| ドラッグ＆ドロップ（中央） | タブグループを作成 / グループに追加する |

---

### タブグループ

タブを別のタブの**中央**にドロップすると、2つのタブがグループにまとまります。  
グループ内のタブをグループ外にドロップすると、自動的にグループから外れます。  
グループに残るタブが1つになった場合、グループは自動的に解散します。

**グループ名の変更：** グループ名をクリックするとその場で編集できます。  
`Enter` で確定、`Escape` でキャンセルします。

**折りたたみ：** グループ横の矢印アイコンまたは色ドットをクリックで折りたたみ／展開できます。

---

### 右クリック コンテキストメニュー

タブを右クリックすると以下のメニューが表示されます。

| メニュー項目 | 動作 |
|---|---|
| このタブに切り替え | タブをアクティブにする |
| 新しいタブで開く | 新しいタブを作成する |
| タブを複製 | 同じページを複製する |
| ピン留め / 解除 | タブをピン留めする・解除する |
| ミュート / 解除 | 音声をミュートする・解除する |
| 新しいグループを作成 | タブ単体でグループを作成する |
| グループを解除 | グループから外す |
| 新しいウィンドウに移動 | 別ウィンドウに切り出す |
| URLをコピー | URLをクリップボードにコピーする |
| タブを閉じる | タブを閉じる |
| 他のタブをすべて閉じる | このタブ以外をすべて閉じる |

---

### ブックマーク表示

ツールバーの「**ブックマーク**」ボタンでブックマーク一覧に切り替えられます。  
フォルダをクリックして階層をドリルダウンでき、上部のパンくずナビで戻れます。

ブックマークを右クリックすると以下の操作ができます。

| メニュー項目 | 動作 |
|---|---|
| 開く | 現在のタブで開く |
| 新しいタブで開く | 新しいタブで開く |
| URLをコピー | URLをクリップボードにコピーする |
| ブックマークを削除 | ブックマークを削除する |

---

### ブックマーク登録（Ctrl + クリック）

タブビューでタブを `Ctrl + クリック`（Mac は `⌘ + クリック`）すると、  
ブックマーク登録ポップアップが開きます。

- 名前を編集して保存するフォルダを選択できます
- すでにブックマーク済みのタブは既存の情報が入力された状態で開き、上書き更新できます

---

### タブ検索

ツールバーの🔍ボタン、または `Ctrl + F` で検索バーを表示します。  
タブ名・URL をリアルタイムで絞り込みます。ブックマークビューでも使用できます。

---

### 新規タブ

ツールバーの `+` ボタンで新しいタブを開きます。  
タブを開くと同時にサイドパネルの検索バーが自動表示されフォーカスされます。

---

### 表示カスタマイズ（設定パネル）

ツールバーの⚙️ボタンで設定パネルを開きます。

| 設定項目 | 選択肢 |
|---|---|
| UIサイズ | コンパクト / 標準 / 大きい |
| 文字サイズ | 極小 / 小 / 中 / 大 / 極大 |
| ファビコン位置 | 左 / 右 |
| タブ名の揃え | 左詰め / 右詰め |
| テーマ | ダーク / ライト / 深夜 |

設定はブラウザに自動保存され、次回起動時も維持されます。

## よくある質問

**Q. タブが表示されない**  
拡張機能ページ（`chrome://extensions/`）で一度削除し、フォルダを再度読み込んでください。

**Q. サイドパネルが開かない**  
アイコンをクリックするとポップアップが表示されます。「サイドパネルを開く」ボタンを押してください。  
Chrome のバージョンが古い場合、サイドパネル API に対応していない可能性があります（Chrome 114 以降が必要です）。

**Q. タブグループが作れない**  
Chrome の設定でタブグループが有効になっているか確認してください。
